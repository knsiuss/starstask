# Action Center Mobile Layout Spec

Last updated: 2026-11-04

## Overview

Order:

1. Title + summary
2. Tabs
3. Four stat cards (2×2)
4. Recent requests
5. Class actions / sidebar details

Stat cards are compact on mobile (`p-4`, `text-2xl` value).

## Assignments

Order: title → tabs → filter bar → request list → pagination.

## Absences

Order: title → tabs → filter bar → request list → pagination.

Detail: status → student info → class/course → period → reason/explanation → evidence → review actions → history.

## Attendance

Order: title → tabs → class selector → session metrics → per-course list → export.

## General mobile rules

- No horizontal overflow.
- No clipped text or buttons.
- Long names and titles wrap.
- Empty states compact.
- Touch targets 40px+.
- Sticky bottom nav does not cover content.
