OBJECTIVE: Audit `supabase/migrations/`, `packages/contracts/`, and `packages/shared/` for RLS coverage, `SECURITY DEFINER` RPC hardening, constraint/index integrity, and contract-to-schema alignment.

OUTPUT: Structured audit findings written to `swarms/full-repo-audit/outputs/T3.md`, ending with `END`. Each finding must include Severity (`HIGH`/`MEDIUM`/`LOW`), `File + Line`, `Evidence`, and `Recommended Fix`.

SOURCES:
- `AGENTS.md` (Sections 7, 8)
- `supabase/migrations/**`
- `packages/contracts/src/**`
- `packages/shared/src/**`

IN SCOPE:
1. Scan `supabase/migrations/` (especially recent `2027*` migrations) for tables missing `ENABLE ROW LEVEL SECURITY` or missing policies, `SECURITY DEFINER` functions missing `SET search_path` or `auth.uid()`/`REVOKE ALL` checks, and broken function references.

3. Check `packages/contracts/src/` and `packages/shared/src/` for schema/DB mismatches, missing bounds (`min`/`max`), or unused/divergent types.
4. Read-only: do NOT edit any source code or SQL files.

OUT OF SCOPE:

- `apps/mobile` & test/lint execution (owned by T4).

DONE WHEN:
- `swarms/full-repo-audit/outputs/T3.md` lists concrete findings with exact file paths, line numbers, and actionable fixes, ending with `END`.

STOP AND ASK IF:
