# Task T1: Web API, Auth, Security & Data Hygiene Audit

OBJECTIVE: Audit all API route handlers and DB data-access modules in `apps/web/src/app/api/` and `apps/web/src/lib/db/` for auth/RBAC, admin-client safety, rate limiting, input validation, and secret/data hygiene.

OUTPUT: Structured audit findings written to `swarms/full-repo-audit/outputs/T1.md`, ending with `END`. Each finding must include Severity (`HIGH`/`MEDIUM`/`LOW`), `File + Line`, `Evidence`, and `Recommended Fix`.

SOURCES:
- `AGENTS.md` (Section 7 & 7.1)
- `apps/web/src/app/api/**`
- `apps/web/src/lib/db/**`
- `apps/web/src/lib/auth/**`
- `apps/web/src/lib/security/**`

IN SCOPE:
1. Verify every route in `apps/web/src/app/api/` enforces server-side auth (`requireSession`, `requireClassMember`, `requireClassManager`, `isAuthorizedCronRequest`, or intentional public read) and never trusts client-supplied `userId`/`role`.
2. Inspect all uses of `createSupabaseAdminClient` in `apps/web/src/app/api/` and `apps/web/src/lib/db/` for authorization & least-privilege scoping.
3. Check for missing rate limiting (`enforceRateLimit`), missing Zod validation on JSON bodies/params, open redirects, `select("*")` leaks, or sensitive fields/PII in error responses/logs.
4. Read-only: do NOT edit any source code files.

OUT OF SCOPE:
- Frontend UI / JSX components (owned by T2).
- SQL migrations & `@starstask/contracts` (owned by T3).
- `apps/mobile` & test/lint execution (owned by T4).

DONE WHEN:
- `swarms/full-repo-audit/outputs/T1.md` lists concrete findings (or verified clean areas) with exact file paths, line numbers, and actionable fixes, ending with `END`.

STOP AND ASK IF:
- Any directory is unreadable or missing.
