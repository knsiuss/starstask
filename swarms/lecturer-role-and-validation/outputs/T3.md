## Summary of Changes

1. **Database Migration (`supabase/migrations/20270125010000_attendance_cutoff_and_grade_validation.sql`)**
   - Added `public.course_grade_weights` table with range constraints (`0 <= weight <= 100`) for `absensi_weight`, `tugas_weight`, `uts_weight`, and `uas_weight`, plus `course_grade_weights_sum_100` (`absensi_weight + tugas_weight + uts_weight + uas_weight = 100`), RLS enabled, and class-member `SELECT` policy.
   - Added `public.compute_weighted_course_grade(...)` immutable SQL helper enforcing `0–100` bounds on all component scores and weights summing to `100`.

5. **Unit Tests (`apps/web/tests/unit/attendance-cutoff-and-grades.test.ts`)**
